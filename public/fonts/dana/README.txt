Dana is a commercial font (FontIran) and is not included in this repository.

1. Buy/obtain a web licence for Dana.
2. Put these .woff2 files in this folder (rename to match):
     dana-200.woff2   (UltraLight / ExtraLight)
     dana-300.woff2   (Light)
     dana-400.woff2   (Regular)
     dana-500.woff2   (Medium)
     dana-700.woff2   (Bold)
   Tip: use the "FaNum" variants if you want Persian digits rendered automatically.
3. Set `danaInstalled: true` in src/data/site.ts and rebuild.

Until then, Persian text renders in Vazirmatn (open source, self-hosted).
